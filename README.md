# OmniAgenda

> **Carpeta `dvlopmnt/Planner/`, proyecto `OmniAgenda`.** La ruta la fijó el dueño el 2026-09-10
> ("todo para este proyecto vive dentro de `/home/bn/DvloprBn/dvlopmnt/Planner`"); el nombre se
> eligió el mismo día. No se renombra la carpeta sin que el dueño lo pida.

**Motor de agenda y reservaciones, replicable, con una aplicación real que lo demuestra.**

No es "un calendario". Es el motor que debió existir antes de que tres proyectos hermanos
escribieran su propia agenda por separado: las citas de tatuaje de Espiral, los eventos y entregas
de Dely Doggy, y la agenda médica que Asclepios tenía planeado copiar a mano.

**Naturaleza:** proyecto de **estudio/portafolio** (vive en `dvlopmnt/`, ver §0.2 del
`PLAN_DESARROLLO.md`), con una exigencia que lo separa del resto: su núcleo tiene que servir de
base real para construir agendas de negocio de verdad — reservación de restaurante, estética,
clínica de tatuajes — no solo demostrar que se puede.
